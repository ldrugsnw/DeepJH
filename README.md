
# DeepJH

A deep learning framework built from scratch using Python and NumPy.

DeepJH is a personal learning project inspired by **『밑바닥부터 시작하는 딥러닝 3』 (Deep Learning from Scratch 3)**.

The goal is to understand how deep learning frameworks work internally by implementing their core components step by step.

## Features

- `Variable` and `Function` abstractions
- Computational graph construction
- Automatic differentiation (backpropagation)
- Gradient propagation through multiple operations

## Tech Stack

- Python
- NumPy

## Project Structure

The project is currently focused on implementing the core automatic differentiation engine.

Additional features, such as neural network layers, optimizers, and training utilities, will be developed as the project progresses.

## Goals

- Understand computational graphs and automatic differentiation
- Explore the internal mechanisms of deep learning frameworks
- Build a lightweight deep learning framework from scratch
